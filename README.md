# 生辰八字命理计算器

一个基于Vue 3和Vite构建的中国传统八字命理计算与分析工具。

## 项目介绍

生辰八字命理计算器是一个现代化的Web应用，结合了中国传统命理学与现代前端技术。通过输入出生年月日时和性别信息，可以快速计算并展示个人的八字命盘、五行分析、命主身主等信息。

## 功能特点

- **八字计算**：支持公历/农历日期转换，精确计算个人八字
- **五行分析**：直观展示金木水火土五行在命盘中的分布情况
- **命理详解**：提供八字基础知识、天干地支、五行相生相克等命理学知识解读
- **个性化分析**：根据性别和出生时间提供个性化的命理分析
- **美观界面**：采用中国传统风格设计，界面典雅美观

## 技术栈

- **前端框架**：Vue 3 + Vite
- **路由管理**：Vue Router
- **样式工具**：UnoCSS
- **命理计算**：iztro 库
- **日期处理**：dayjs
- **图标支持**：@iconify/vue

## 安装与使用

### 环境要求

- Node.js 16.0+
- npm 或 yarn

### 安装步骤

1. 克隆项目到本地

```bash
git clone [项目地址]
cd EightChart
```

2. 安装依赖

```bash
npm install
# 或
yarn install
```

3. 启动开发服务器

```bash
npm run dev
# 或
yarn dev
```

4. 构建生产版本

```bash
npm run build
# 或
yarn build
```

## 使用说明

1. 在首页选择"开始测算"或"八字详解"
2. 在计算页面输入出生年、月、日、时辰、性别和历法（公历/农历）
3. 点击"计算八字"按钮获取分析结果
4. 在结果页查看八字命盘、五行分析和个性化解读
